## Get a local copy

Open a terminal in the parent folder where you want the project and run:

```bash
git clone https://github.com/1764868036-cell/CityAndRuralConjunction.git
cd CityAndRuralConjunction
```

If you have already configured an SSH key with GitHub, you can use this clone URL instead:

```text
git@github.com:1764868036-cell/CityAndRuralConjunction.git
```

Use one clone method. HTTPS and SSH point to the same repository.

## Working together

1. Update your local `main` branch.
2. Create a branch for one task.
3. Edit files and inspect the changes.
4. Commit and push your branch.
5. Open a pull request into `main` and ask another group member to review it.
6. Merge after review, then update your local `main`.

See [CONTRIBUTING.md](CONTRIBUTING.md) for commands, worksheet mappings, and issue tracking guidance.
