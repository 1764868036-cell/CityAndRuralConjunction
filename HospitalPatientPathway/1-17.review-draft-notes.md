# 1-17 BPMN review draft notes

This is a review copy. The original `1-17.bpmn` is unchanged.

## Included in this draft

- Restores the original 11 hospital responsibility lanes in the hospital participant.
- Keeps responsibility lanes inside subprocesses so stage ownership remains visible when a subprocess is opened.
- Assigns top-level routing and summary nodes to a hospital role lane instead of a generic orchestration lane.

## Not yet included

- P01–P08 are still represented as subprocesses in this review copy. The confirmed target is to lift their activities into the main process; that structural rewrite is not complete here.
- P09–P17 remain regular embedded subprocesses in the current review copy, but their cross-scope entry/exit routing has not been reworked for the confirmed hybrid structure.
- Camunda 8 form bindings and Java Job Worker mappings have not been audited in this lane-only draft. Do not deploy it as the final process.
