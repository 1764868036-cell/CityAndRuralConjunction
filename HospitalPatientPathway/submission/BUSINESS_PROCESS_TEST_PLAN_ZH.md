# 医院患者路径业务流程测试计划

文档版本：V1.1　修订日期：2026 年 9 月 29 日　提交标签：`hospital-pathway-final-2026-09-29-r4`。适用模型：`1-17.bpmn`，SHA-256 为 `616af009cf00ec674ef7371d48071f8c015b44c1c65f0cf15bd550dc2e9a960b`。

本计划供项目提交人与评阅者安排、复核业务流程测试。测试对象是 `1-17.bpmn` 中唯一可执行的医院流程，以及与它一起部署的 16 个 Camunda Forms 和 Java External Workers。当前证据能够说明本地原型的主路径与若干分支已运行；**尚不能据此认定全部验收场景通过或真实医院系统可上线**。每个场景的完整前置条件、数据、步骤和预期结果见 `ACCEPTANCE_TEST_PLAN.md`；本文件说明执行顺序、判定办法、证据要求与剩余工作。

## 一 测试边界与依据

测试覆盖转诊登记与资料补齐、临床评估、咨询预约、知情同意、服务与资助、付款、治疗变更、预约改期和取消、退款或转款、问询与信件、访问授权及系统中断恢复。对每条路径同时核对人工作业、网关条件、外部消息关联键、Worker 结果、最终状态和持久化记录。权限拒绝、身份核验失败、重复收费、计时器及并发信件是重点风险。

本轮环境只使用合成患者资料。外部转诊方、预约服务、资助方、支付服务等由本地模拟器提供回复；已完成实例不能证明真实第三方接口、真实身份体系或临床安全性。性能、渗透测试和生产数据治理另设专项验证，不纳入本轮本地原型准出结论。

主要依据是可编辑模型 `1-17.bpmn`、`Form_Task_Mapping.csv`、`java/WORKER_MAP.md`、`submission/ACCEPTANCE_TEST_PLAN.md`、`submission/DESIGN_DECISIONS.md` 和 `submission/DEPLOYMENT.md`。以模型内的业务规则 R-01 至 R-13、BR-01 至 BR-11 为判定依据。临床“紧急”“适宜”及资助政策未获得独立的量化规范；测试不得自行编造阈值。

## 三 业务场景与验收重点

## 四 执行顺序与证据记录

已完成的本地阶段：2026 年 9 月 28 日的部署、模型／表单审计及 13 个合成实例抽样；9 月 29 日的 Java 全套测试与 FEEL 规则验证。后续日期需由项目方确定，不能把本计划当作已完成的历史 sprint 日志。

1. **环境复核**：记录 Git 标签、模型哈希、部署响应与 Worker 启动结果；失败时先修复环境，不把连接错误记成业务缺陷。
2. **安全关键分支补测**：优先执行 AT-05 至 AT-08、AT-11 的日期／联系边界、AT-13 的未授权退款。每个输入组合使用独立实例。
3. **异步流程补测**：执行 AT-09 的冲突决策、AT-14 的疑似错误、7 天／23 天／两个月提醒及两封并发信件；记录消息关联和计时器触发时间。
4. **回归与评阅**：重跑 `java/` 下的 `./mvnw.cmd -q clean test`，核对新增场景、缺陷关闭情况和最终提交标签。评阅者可复现关键实例。

每次执行形成一条证据记录：AT 编号、运行时间、版本和 BPMN SHA-256、唯一实例 ID、前置数据、Tasklist 提交值、外部消息名及 correlation key、元素轨迹、最终状态／incident、预期与实际差异、执行人和缺陷编号。可附任务界面截图，但截图不能取代实例轨迹。当前证据位于 `evidence/tests/`、`evidence/validation/` 与 `evidence/runtime/`；结果映射见 `submission/TEST_RESULTS.md`。

## 五 缺陷处理与准出结论

发现路径错误、错误关联、未经授权操作或数据不一致时，记录复现数据、实例 ID 和实际轨迹，修复后用新实例回归，并重跑受影响的相邻路径。当前提交未提供独立的历史缺陷管理系统导出；不能补造“零缺陷”或审批记录。

**本地演示准入**：模型与 Forms 部署成功、Workers 可运行、合成数据准备完毕、至少主路径能完成。**课程提交准出**：模型、Workers、Forms、计划、结果与证据可从同一公开 Git 标签取得；实际执行与待执行场景分开标注；目标版本重跑的 28 项 Java 测试全部通过，已归档实例无未解释的阻塞 incident。**生产准出**需要所有安全关键与时间相关场景实际通过，并另行完成真实接口联调、临床规则确认、权限及数据治理评审；本计划不宣称达到生产准出。

截至本版，Java 测试 **28／28 通过、0 失败／错误／跳过**；53 个 FEEL 场景通过；13 个已归档的模拟实例状态为已完成且无 incident。AT-05 至 AT-08 等仍有未执行的 token 路径，故整体结论是**本地原型已演示，完整验收尚未完成**。详见 `TEST_RESULTS.md` 和 `EVIDENCE_CLOSURE_RECORD.md`。
